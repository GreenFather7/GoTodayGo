# GoTodayGo

Каждый пост — одно Telegram Rich Message. Сверху расположена фотореалистичная иллюстрация без надписей, под ней — крупный заголовок, текст цитаты и ссылка на канал «Сегодня тот самый день».

Канал публикует короткие мотивирующие высказывания известных предпринимателей, спортсменов и философов. В одном посте — одна мысль, ориентир для русской цитаты — до 16 слов и 110 знаков. Фотография передаёт мысль цитаты через конкретную сцену. В карточке редактор хранит имя автора и ссылку на выступление, интервью, письмо или книгу для проверки цитаты. Для переводных высказываний поле `original` хранит точные слова источника, а `text` — русский текст. Оба текста учитываются при проверке повторов.

## Время выхода

Каждые три часа открывается окно для одного поста. Начало окон по Москве — 01:18, 04:18, 07:18, 10:18, 13:18, 16:18, 19:18 и 22:18. Отправщик проверяет текущее окно каждый час на 03-й, 18-й, 33-й и 48-й минутах. Успешный плановый замер просмотров в ветке `main` также запускает проверку. Если в журнале уже есть запись для этого окна, отправщик пропускает его. GitHub Actions может задержать или пропустить плановый запуск. Следующая проверка позволяет отправить пост, пока окно открыто.

## Очередь

- `cards.json` содержит готовые посты по порядку. Изображения находятся в `media/`. Чтобы добавить готовый пост, укажите `title`, `text`, `photo`, `source_url` и, когда известно, `author`.
- `reserve.json` содержит проверенные цитаты, заголовки и сюжеты для следующих иллюстраций. Когда резерв заканчивается, редактор выбирает среди сверенных английских фраз предпринимателей и спортсменов из `english_sources.json` и коротких высказываний философов из электронного издания. При выборе учитываются уже опубликованные оригиналы и русские тексты.
- `archive_texts.json` содержит отпечатки доступных текстов из публичной истории канала на 19 ноября 2026 года. В `publication-state.json` сохраняются заголовок и текст в нормализованной форме, отпечаток изображения и состояние отправки. Пост №3507 уже отмечен опубликованным.
- Для нового слота процесс выбирает первую доступную карточку и фиксирует её в журнале на GitHub перед запросом к Telegram. Если подтверждение доставки потерялось, карточка остаётся зарезервированной. В этом случае проверьте историю канала и журнал выполнения. По исчерпании доступных материалов очередь останавливается до пополнения.

## Подключение и проверка

1. Включите GitHub Actions для репозитория. Ветка по умолчанию должна разрешать процессу коммиты журнала через `contents: write`.
2. В **Settings → Secrets and variables → Actions** укажите `TELEGRAM_BOT_TOKEN` для бота, которому выдали право «Публикация сообщений» в канале. Если токен был раскрыт, обновите его через @BotFather и сохраните актуальное значение в секрете.
3. Для автоматической подготовки следующих иллюстраций добавьте туда же `OPENAI_API_KEY` с доступом к API генерации изображений. Вызовы оплачиваются владельцем ключа. Готовым постам хватает токена Telegram.
4. Откройте **Actions → GoTodayGo → Run workflow**. По умолчанию ручной запуск показывает наличие секретов и предпросмотр следующей карточки. Для восстановления пропущенной публикации выберите ветку `main` и включите **«Опубликовать пост, если текущее трёхчасовое окно свободно»**. Отправщик проверит журнал и опубликует одну карточку, если окно ещё свободно и открыто. Для остановки откройте **Disable workflow**.

Локальный предпросмотр из корня репозитория — `python3 publish.py`. Бот использует [нативные Rich Messages Telegram](https://core.telegram.org/bots/api#sendrichmessage).

После публикации бот скачивает из Telegram фотографию первого блока и сравнивает её с исходником. При успешной проверке он сохраняет размеры фотографии в журнале. Чтобы восстановить фото готовой карточки, в **Run workflow** укажите номер существующего сообщения в поле **«Исправить фото в существующем посте по номеру сообщения»**. Бот сверяет текст и исходный файл с журналом и редактирует пост по прежней ссылке.

Для применения нового оформления к опубликованным карточкам укажите их номера через запятую в поле **«Обновить текст существующих постов по номерам через запятую»**. Бот найдёт оригиналы в журнале, применит текущий шаблон и проверит фотографию в каждом отредактированном сообщении.

## Две недели наблюдений

С первой подтверждённой плановой публикации после 19 ноября 2026 года, 19:18 МСК включительно, начинается 14-дневный набор постов. Ранее опубликованный вручную пост №3507 в выборку не входит. В три приоритетных слота (16:18, 19:18 и 22:18 МСК) отправщик учитывает, какие темы и авторы уже выходили в каждом из этих слотов. При совпадении условий он следует порядку очереди.

Отдельный процесс `measure.yml` дважды в час проверяет, каким постам исполнились сутки. Если Telegram показывает счётчик в возрасте от 24 до 25 часов, процесс сохраняет первое такое показание и точное время наблюдения. Сокращения вроде 13.8K учитываются с точностью отображения Telegram. Пропущенные замеры, задержки выхода и размеры групп видны в [отчёте](experiment-report.md). Группировка для сравнения использует фактический час отправки по Москве. После последнего окна измерений процесс сбора завершится; расписание публикаций продолжит работать.
